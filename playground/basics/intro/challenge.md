## Challenge : Intro / Execution Model

**"The Case of the Missing Output"**

A classmate hands you a Java file. It compiles with no errors. When they run it with `java Program`, nothing prints, the program just exits immediately with no output and no crash. They swear the file has a `main` method that prints something. You don't get to see the file's exact contents, but you're allowed to ask them targeted yes/no questions to diagnose the problem, using only what you've learned in this concept (nothing about arrays, strings, or OOP).
Write out the sequence of diagnostic questions you would ask, in the order you'd ask them, and for each question, explain what answer would confirm the cause and why. There is more than one plausible root cause consistent with "compiles fine, runs with no output, no crash", your job is to narrow it down systematically, the way you'd debug a real silent failure.
